EMBER DEPTHS
Open index.html in a desktop or mobile browser. Keep the js/ and sprites/ folders next to it.
Progress is saved in the browser (3 slots). The Menu has save codes for moving a character between browsers; codes from older versions still import (as Normal difficulty).

Controls: WASD move | Left click / Space main hand | Right click / K off-hand (melee or ranged) | 1-4 abilities | Z X C V consumables
Shift dash | F interact, shop, forge, mine (hold) | T skill trees | I pack | Esc menu

Rebuild the pixel art (optional, needs Python + Pillow): python3 tools/make_sprites.py
